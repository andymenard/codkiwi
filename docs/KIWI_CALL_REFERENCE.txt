# Cause of Death: native call and behavior reference for RenPy conversion

Revision: 2026-09-12. This supersedes the syscall descriptions and runtime-status claims in the earlier CLAUDE_HANDOFF.md and PRESENTATION_CUE_FINDINGS.md. Project: outputs/cod-replica-lab. The older outputs/cod-web-lab remains a preserved milestone.

## Scope and evidence

This is a source-derived behavioral reconstruction of the supplied iPhone CoD 1.3.4 ARMv7 executable, plus static analysis of 103 expansion containers. It is not a claim of complete 1:1 equivalence. All 100 syscall dispatch slots are accounted for, including native defaults; later corpus call100 is separately documented. Static parsing covers 420 script instances / 368 unique SHA-256 scripts, with no parser errors. Passing replica tests and reaching dialogue are not original-device differential validation.

Descriptive call names below are ours. IDs, native handler addresses, native function names and data-flow observations are evidence; uncertain semantics are explicitly labeled. Ghidra mangles several C++ by-value CSString signatures: trust verified register/stack argument order rather than its displayed prototype. Every row includes observed static invocation counts and argument counts. Counts include duplicate scripts; an unobserved syscall may still matter in bundled scripts or unexamined versions.

Evidence files in outputs/native-evidence retain disassembly/decompilation excerpts and recovered functions. Inputs remain in the user's Desktop/Decompile folder. No original native app execution or fresh SHS differential playback was completed during this pass.

## Calling convention and strings

Cells and ordinary registers hold 16-bit values. Use signed16 for native numeric parameters, retaining unsigned16 bit patterns for addresses/serialization. Raw opcode0x1f embeds syscallID in high operand byte and argc in low byte; raw0x1e uses its operand as ID and current SYS as argc. Arguments are stack[SP-argc] through stack[SP-1], in that order (a0 first). Return removes argc cells and sets SYS to low16 result. Blocking calls keep args and pending argc until UI completion. Native no-result sentinel0x80000000 ultimately produces low16 zero when not blocked.

VM strings pack high byte then low byte in each short, NUL terminated. Native readBufferString(0x36f04) special-cases exactly signed pointer -1 to empty string (literal0x101420). Other negative pointers are not empty-string sentinels. Positive pointers0x7ff5..0x7ffe address ten host CSString slots;0x7fff overlaps scratch storage. Native does not reliably bounds-check invalid string selectors. Replica decodes Windows-1252; exact native encoding and non-ASCII casing/entry remain unverified. Helpers 6/47 select slot by complement of a negative selector; helper0 instead selects 1-selector. Do not unify these formulas.

Named substitutions and speaker names should remain dynamic until presentation. Preserve raw strings alongside rendered strings when converting so player-name substitution works after load/rollback. Current replacement loop is bounded and diagnoses cycles; unusual replacement ordering needs native comparison.

## Scheduler and durable state

Entry is resource25001 (0x61a9) in the supplied corpus. Run initialization before narrative modules: it installs entity names, portraits and properties. Queued scripts are LIFO after halt. queueScript09's Boolean suppresses default dialogue creation; it is not a library flag. Mutable state spans scripts: names, replacements, integer properties/arrays, portrait definitions, expressions, speakers, pending audio and UI. Starting a new VM does not mean resetting the story world.

Keep dialogue UI as a persistent underlying object and menus/cards/input as transient layers. Call13/65 with absent dialogue does not wait. Generic UI completion returns zero; menu results and text-entry results have separate contracts. Frame stack uses1024 cells, address base0x7bf5; popped cells retain their native memory contents. The replica diagnoses uninitialized or out-of-range access rather than inventing zero. Optional library ownership remains incomplete. Parser reserves secondary cells as zero, but native initialization of that region still needs confirmation.

## Every syscall

Arguments below are zero-based positional order. A missing native side effect is not permission to infer a replacement behavior. Host-dependent calls can be adapted explicitly in RenPy, with any behavior change recorded.

### 0 — format_host_string

Arguments: `format, substitutions… OR negativeSelector, format, substitutions…`. Return: **host-string pointer**. Native target: `0x384a0`.

Formats %c, %d, %s via my_sprintf2(false). Nonnegative first argument selects slot 0; negative first argument selects slot 1 - signed(a0), with format in a1. Unlike calls 6/47, this selector is not bitwise complement. Native ten persistent string slots plus scratch; malformed selectors are unsafe. Current format scanner is approximate for unsupported percent sequences.

Replica: source-derived; implementation partial where noted. Static corpus: 7455 sites; observed argc: 1, 2, 3, 4.

## Media/resource behavior

Resource scope is selected by SHSEngine::getResMgr: signed ID >=26000 uses current expansion; lower IDs use bundled resources. This threshold is distinct from the script IDs25000..25999. Extracted expansion files use hexadecimal names asset_6590.jpg; original bundle res_generated names are decimal with no extension. Identify content by signature. Keep a manifest for both scopes; missing expression/background variants must fall back based on actual resource existence, not on a guessed naming pattern.

Portraits: call72 registers base through base+4, each absent variant falls back to base. Speaker expression selection clamps negatives to0 at the speaker layer and indexes modulo5; last/persisted expression caches are not interchangeable. Keep entity, expression and resolved resource ID in exported traces. Primary/event speakers affect layout/narration. Current portrait event includes narration state; exact original alignment and animation interpolation remain unfinished.

Locations: dialog.setLocation(base,variant) consumes -2 as KEEP independently for each field. GameModel::setLocationImageID returns without change for negative base; normal variant1 uses base+1,2 uses base+2, other variants use base. Missing candidate falls back to base. A direct GameModel call with variant-2 has time-dependent logic around thresholds1080/1200, but the ordinary dialogue call consumes -2 first. Do not apply the direct time-of-day rule to the script-facing KEEP sentinel. Wipe function0x10260 is empty. Pan/alignment call97 still matters independently.

Image cards: call8 constructs SHSUIChapterScreen, storing title/text and two resource/parameter shorts at+0x80/+0x82. It is a transient screen, not dialogue text plus an ordinary background change. Secret Files uses both title and text=-1 with expansion artwork in a2. Browser shows that artwork as a card. Precise compositing of a3 is not recovered; native C++ render stub is empty, suggesting presentation elsewhere (Objective-C/widget path).

Audio: GameModel::tick09Expansion calls runScript09 before handleQueuedAudio. Each pending slot holds only the latest request; flush sound first, music second, then clear. Sound manager accepts built-in effects8001..8006 and expansion>=26000, and built-in music8201..8209 and expansion>=26000. Enabled/volume flags can suppress playback. Re-requesting currently selected music updates looping and cancels fade rather than unconditionally restarting. Switching tracks may defer new playback until fade completes; the bare-bones adapter does not reproduce that precise scheduling. stopMusic(-1) selects duration1000 and clears pending music. Calls83/84 pause/resume,82 vibrates. Original files are retained; nothing is regenerated.

LocalMediaAdapter is deliberately separate from native-effects.js: browser rendering, HTMLAudioElement playback and approximate millisecond fade are implementation choices. It displays original JPEG/PNG/GIF assets and plays recognized MP3 assets selected locally. It does not implement every original codec, title-card composition, device vibration, crop/pan animation, volume settings, track positions in saves, or original UIKit behavior. Loading only .kiw scripts cannot resolve actual image fallback correctly; supply manifests/assets. No browser-side LZMA extraction yet: run the Python extractor first.

## Menu timing and action minigame

Native menu initializes remaining/initial duration as floats converted from signed integer duration. On tick, subtract delta; timeout fires only when remaining <0 and initial >0 and no pending selection. Exact real-time unit conversion and selection/animation boundary need original playback comparison. Browser offers explicit advancement in native units, so readers can exercise timeout branches without claiming wall-clock parity.

Action-menu reset draws one good item, one bad, and a different second bad. Coin arc4random()&1: even draws a different second good; odd draws a third distinct bad. Initial scores are [+1,-1,-1,+1 or -1]. Shuffle with exactly20 swaps, each choosing two indices from separate arc4random()&3 draws. Clicking clamps accumulated score to at least0; it does not return to VM. Timeout returns accumulated score. Native flies old choices off and schedules new choices through NSTimer; current replica regenerates immediately. RoundPeriod and disabled-input window remain incomplete. The replica requires at least2 good and3 bad entries, preventing native infinite distinct-draw loops for malformed pools.

Randomness: CSEngine::rand resolves to arc4random at import stub0xee0f8, followed by signed absolute-value logic. Minigame uses unsigned arc4random directly. Do not substitute an assumed libc seed. Replica records cryptographic random words in a tape and saves cursor/tape; exported traces can supply the tape for repeatability. The corpus exploration tool uses an explicitly synthetic fixed RNG, only for reproducible coverage. Save replay is deterministic only over already recorded words; exhausting a stored tape can draw new entropy.

## VM binary format and complete opcode table

CSPUD starts with 5 ASCII bytes, then big-endian u32 resource count. Each index entry is big-endian u16 resource ID and u32 record offset. Each record has compressed size at+0, raw size at+4, an as-yet uninterpreted field at+8, and payload at+12. If compressed==raw the extractor copies bytes; otherwise decode LZMA1 using the first property byte and little-endian dictionary size in a13-byte header, with compressed stream after that header. Verify raw output length. tools/unpack_exp.py preserves resource content after decompression.

Kiwi starts with ASCII kiwi, one-byte version, for version>1 a library-present Boolean and optional two big-endian shorts, then external-instruction-set flag. Next four big-endian u16: primary, secondary, tertiary, instruction count. Serialized data contains primary+tertiary shorts; memory reserves primary+secondary+tertiary with secondary gap between primary and tertiary. Then instructions: raw opcode byte, optionally big-endian u16 operand. Always operand for raw01,40,41,5c. Within19..2e use mask0x003f84e7 at bit(raw-0x19). Never allow JavaScript shifts to wrap the mask outside that interval. Header library/external instruction-set support is incomplete; do not assume every Kiwi variation is supported.

Instruction pointer below is decoded instruction index, not byte offset. Let i be the index of the current instruction before execution. Ordinary next IP is i+1. Arithmetic outputs wrap to16 bits. For two-stack-value operations, a is preceding/lower cell, b is top cell. Binary operations pop both and push result. Relative jump target is i+signed16(operand). All98 in-range raw opcode slots follow; out-of-range0 or>0x62 falls through in this executable.

## Native save-state layout recovered so far

CSKiwiEngine::saveState(0xeac8) writes: state byte; IP short; SP short; BP short; PRI short; ALT **32-bit int sign-extended from short**; SYS short; stack capacity short; capacity stack shorts (including inactive cells); then secondary+tertiary mutable data shorts (excluding primary). ALT is not serialized as a short.

SHSScript save adds10 host strings, each presence Boolean followed by writeUTF when present. saveEventInfo separately writes eventText UTF,10 result shorts, then shorts from fields0x74(argc),0x76(script resource),0x78,0x7c,0x80; Booleans0x84 and0x85. Unknown fields should keep literal names until traced. UI elements and GameModel add further state.

Entity table save includes200 name UTF strings, integer-property count and native raw key/value arrays, keyed integer arrays,200 expression bytes,2000 portrait bytes. Raw native arrays and stream writeInt may differ in byte order: do not assume one endian convention for the full save. CSDataStream UTF framing/encoding and whole-file/version framing still need validation. GameModel save/load decompilations are included in evidence.

Browser snapshots are JSON version2 with volume fingerprint, VM backing stack/registers/cells/pending syscall, script queue, properties, arrays, names, replacements, portrait/effect state, UI, random tape/cursor, event text/results. These snapshots are NOT compatible with cod_expansion.sav or cod_options.sav. Browser media playback positions are not serialized. Native save import/export remains unfinished.

## Integration approach for Claude's RenPy revival

1. Keep the existing revival's artwork/UI organization. Introduce a semantic adapter keyed by numeric syscall ID; avoid copying browser DOM behavior into RenPy.
2. Either port the small Kiwi VM and host model to Python, or translate control flow to labels while retaining all property writes, return values, conditional branches, queue order and delayed interactions. A linear dialogue transcript is insufficient.
3. Store entity/property maps, arrays, names, expression/portrait state, location fields and event results in rollback-aware RenPy state. Preserve a pending call until the corresponding screen/menu/input returns.
4. Resolve resources through separate bundled/expansion manifests, then map their IDs to existing revival assets. Preserve original resource ID in logs even when using a renamed file. Resolve expression and location fallbacks by actual existence.
5. Buffer sound/music until the equivalent script-run boundary; do not immediately play every call79/80 in sequence. Use the recovered loop Boolean and explicit stop/fade duration. Record any intentional adaptation of native timing.
6. Map normal dialogue to say, menus to screens with numeric return mapping, call8 to an image-card screen, call17/40 to input, call71 to a timer-driven action screen and call78 to a portrait-choice screen. Preserve disabled options and timeout paths.
7. Use tools/export-trace.js with explicit action JSON to compare the revival against the replica, then compare both against original iOS/SHS capture. A replica-vs-revival match alone does not resolve native uncertainty.
8. Treat platform-only calls9,30,87,95 and newer-version call100 as explicit integration decisions. They are never silently converted into arbitrary story progression.
